# Calculadora de Média com Python

Este repositório faz parte da minha jornada de transição de carreira da área industrial para a Tecnologia e Análise de Dados. 

## Descrição do Projeto
O objetivo deste projeto foi aplicar os conceitos iniciais de lógica de programação em Python, focando na criação e estruturação de **funções (`def`)** e estruturas de repetição (`for`). O código recebe uma lista de números (que simula dados de vendas ou produção) e calcula a média aritmética de forma automatizada.

## Tecnologias Utilizadas
* Python 3 

##  Aprendizados Chave
* Criação e chamada de funções personalizadas.
* Lógica de acumuladores e laços de repetição.
* Utilização da função embutida `len()` para contagem de elementos.
